## TaskFlow - Daily Planner 

TaskFlow is a daily task and time management application, designed to help users optimize personal productivity through the time allocation method (Calendar Blocking). The application provides an intuitive, easy-to-use interface and has been refined, packaged ready for release on the Microsoft Store platform.

## Features

*   **Calendar Blocking:** Visualize the daily schedule, allowing you to easily allocate specific time blocks for each task.
*   **Quick task addition operation:** To add a new task to the calendar, users just need to double-click directly on the desired time slot on the interface (Note: The system is optimally designed for click operations instead of drag-and-drop to ensure accuracy).
*   **Comprehensive Task management:** Supports creating, editing and tracking daily work progress seamlessly.
*   **Optimized interface (Clean UI):** Friendly design, interface bugs have been fixed to bring the smoothest experience.

## Technology

*   **Language & framework:** Python, PySide6.
*   **Database:** SQLite.
*   **Packaging:** PyInstaller.

## Installation

1. **Download application:** Download the installation file `TaskFlow-v2.0-setup.exe` from the release.
2. **Installation:** Run the `.exe` file and follow the on-screen instructions to install the application on the machine.
3. **Usage:** 
    * Open the TaskFlow application.
    * At the main calendar screen, double-click on an empty time slot to open the add task dialog.
    * Fill in the task information and save to start managing your time!
